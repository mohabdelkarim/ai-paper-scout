## 1. A Common Measure of Communication for Speech Brain-Computer Interfaces

**Authors:** Dulhan Jayalath, Benjamin Ballyk, Oiwi Parker Jones

**TL;DR:** The paper introduces OVMI, an open‑vocabulary mutual information metric that lets researchers compare speech‑brain‑computer interface systems on a common scale, revealing trade‑offs between vocabulary size and decoding accuracy.

**Key Innovation:** Derivation of the open‑vocabulary mutual information (OVMI) metric that quantifies the information a speech‑BCI decoder conveys relative to a reference word distribution, enabling cross‑system comparison and principled vocabulary selection.

**Why It Matters:** Engineers can use OVMI to design and evaluate speech‑BCI vocabularies that maximize user communication, improving the practical performance of assistive speech devices for people with paralysis.

**Tags:** speech-brain-computer-interface, open-vocabulary, mutual-information, communication-measure, neural-decoding

## 2. Discriminative World Models for Web Agents

**Authors:** Kelvin Li, Dhruv Pendharkar, Anish Pahilajani, Chuyi Shang, Leon Oks, Leonid Karlinsky, Rogerio Feris, Trevor Darrell, Roei Herzig

**TL;DR:** They train web‑agent world models to produce representations that can distinguish the correct next page from alternatives, leading to better action selection.

**Key Innovation:** A predicted‑state matching objective that forces world‑model representations to be discriminative across candidate actions, rather than just predicting next‑state snapshots.

**Why It Matters:** Enables web‑automation systems to more accurately rank possible clicks, improving success rates for tasks like booking tickets or filling online forms.

**Tags:** world-models, discriminative-training, web-agents, action-ranking, web-automation

## 3. Graph Machine: Towards Better Pretraining via Edges

**Authors:** Lintai Hou

**TL;DR:** Graph Machine introduces a sparse, dynamically routed Transformer architecture that uses differentiable pointer-like edges to maintain an O(n)-sized state while keeping layer complexity linear, enabling efficient large‑scale language model pretraining.

**Key Innovation:** A novel sparse Transformer design that replaces dense layers with dynamic routing through differentiable pointer-chasing edges, allowing O(n) state access without sacrificing sparsity or increasing per‑layer complexity.

**Why It Matters:** It allows engineers to train and deploy large language models with significantly reduced memory and compute requirements, making it feasible to run state‑of‑the‑art models on commodity GPUs or in edge environments.

**Tags:** sparse-transformer, dynamic-routing, pointer-chasing, graph-machine, pretraining-optimization

**Link:** [http://arxiv.org/abs/2609.02881v1](http://arxiv.org/abs/2609.02881v1)
