## 1. Honeycomb-Surfels: Compact Hexagonal Primitives for Efficient Scene Rendering and Reconstruction

**Authors:** Prakhar Kaushik, Soumava Paul, Alan Yuille

**TL;DR:** Hexels are hexagonal surface elements with per‑primitive color fields that let neural rendering and 3D reconstruction achieve higher quality than 2D Gaussian splatting while using less GPU memory and running faster.

**Key Innovation:** Introducing hexagonal planar primitives (Hexels) that combine area‑efficient hexagonal support with a first‑order spatial color field, enabling compact, high‑fidelity scene representation and efficient rendering.

**Why It Matters:** Allows AR/VR and mobile applications to generate photorealistic novel views and accurate 3D meshes on devices with limited GPU memory, improving real‑time performance and reducing deployment cost.

## 3. When Should We Intervene at Test Time?

**Authors:** Jiahao Zhang, Xinling Wen, Liangliang Li, Yu Chen

**TL;DR:** PORTAL is a lightweight controller that decides when to apply test‑time interventions, which samples to label, and when to stop, using only a few labels to avoid hurting overall accuracy.

**Key Innovation:** A principled decision framework that evaluates all candidate prediction rules on shared labeled samples, directing queries to candidates that can still overtake the current leader and stopping when further labels cannot change the choice, with theoretical analysis linking required feedback to accuracy gaps and shared mistakes.

**Why It Matters:** In real‑world vision deployments (e.g., autonomous driving or surveillance) where input distributions shift and class imbalance varies, PORTAL enables the system to selectively apply normalization or other adaptation only when it will help, preventing performance drops on problematic batches and ensuring reliable operation under changing conditions.

**Tags:** test-time-adaptation, label-efficiency, online-adaptation, distribution-shift, decision-controller

**Link:** [http://arxiv.org/abs/2610.37658v1](http://arxiv.org/abs/2610.37658v1)
