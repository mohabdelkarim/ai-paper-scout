## 1. SpatialClaw: Rethinking Action Interface for Agentic Spatial Reasoning

**Authors:** Seokju Cho, Ryo Hachiuma, Abhishek Badki, Hang Su, Byung-Kwan Lee, Chan Hee Song, Sifei Liu, Subhashree Radhakrishnan, Seungryong Kim, Yu-Chiang Frank Wang, Min-Hung Chen

**TL;DR:** This paper proposes SpatialClaw, a framework for spatial reasoning that uses code as the action interface, allowing vision-language models to flexibly compose and manipulate perception results for open-ended 3D/4D spatial reasoning tasks

**Key Innovation:** The use of a stateful Python kernel as the action interface, enabling the agent to write executable code conditioned on prior outputs and adapt its analysis to intermediate observations

**Why It Matters:** SpatialClaw achieves state-of-the-art performance on 20 spatial reasoning benchmarks, outperforming recent spatial agents and demonstrating its potential to improve vision-language models' ability to reason about complex 3D/4D spatial relationships

**Tags:** vision-language models, spatial reasoning, action interface, code generation, 3D/4D spatial reasoning

**Link:** [http://arxiv.org/abs/2606.13673v1](http://arxiv.org/abs/2606.13673v1)

## 2. Aerial Wildfire Suppression Planning with a Hybrid CNN-Cellular Automata Fire Model

**Authors:** Ion Matei, Maksym Zhenirovskyy, Takuya Kurihana, Rohit Vupala, Anthony Wong

**TL;DR:** This paper presents a framework for aerial wildfire suppression planning using a hybrid CNN-Cellular Automata fire model and gradient-based optimization to design effective intervention strategies

**Key Innovation:** The combination of a hybrid neural-cellular automaton wildfire model with gradient-based design of targeted aerial drops to predict fire spread and determine optimal intervention strategies

**Why It Matters:** The framework can generate coherent aerial suppression schedules to reduce total fire-affected area and support uncertainty-aware analysis of wildfire intervention strategies, which can inform decision-making in real-world wildfire scenarios

**Tags:** wildfire suppression, aerial firefighting, CNN-Cellular Automata, optimization, uncertainty quantification

**Link:** [http://arxiv.org/abs/2606.13633v1](http://arxiv.org/abs/2606.13633v1)

## 3. Distribution-Agnostic Robust Trajectory Optimization via Chance-Constrained Reinforcement Learning

**Authors:** Yashdeep Chaudhary, Roberto Armellin, Harry Holt, Marco Sagliano

**TL;DR:** This paper presents a robust trajectory optimization framework using chance-constrained reinforcement learning that can handle uncertain conditions without requiring a specific distribution

**Key Innovation:** The use of rollout-based upper-tail quantiles and covariance-feasibility penalties to enforce probabilistic feasibility in a distribution-agnostic manner

**Why It Matters:** The framework can be applied to various spacecraft trajectory planning problems, providing a competitive and robust solution for fuel cost optimization while preserving probabilistic feasibility under different types of uncertainty

**Tags:** reinforcement learning, trajectory optimization, robust control, chance-constrained optimization, spacecraft trajectory planning

**Link:** [http://arxiv.org/abs/2606.13605v1](http://arxiv.org/abs/2606.13605v1)
