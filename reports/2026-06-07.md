## 1. Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models under Software Evolution

**Authors:** Liliana Hotsko, Yinxi Li, Yuntian Deng, Pengyu Nie

**TL;DR:** Code2LoRA is a hypernetwork framework that generates repository-specific adapters for code language models, enabling efficient and adaptive modeling of evolving codebases

**Key Innovation:** Hypernetwork-generated LoRA adapters that inject repository knowledge with zero inference-time token overhead

**Why It Matters:** Code2LoRA improves the efficiency and adaptability of code language models, particularly in scenarios with evolving codebases, and achieves state-of-the-art results on the RepoPeftBench benchmark

**Tags:** code language models, hypernetworks, LoRA adapters, software evolution, repository-specific modeling

**Link:** [http://arxiv.org/abs/2606.06492v1](http://arxiv.org/abs/2606.06492v1)

## 2. You Only Index Once: Cross-Layer Sparse Attention with Shared Routing

**Authors:** Yutao Sun, Yanqi Zhang, Li Dong, Jianyong Wang, Furu Wei

**TL;DR:** This paper proposes a new sparse attention method called cross-layer sparse attention, which improves the efficiency and quality of long-context inference in large language models

**Key Innovation:** The core idea is to share the routing index across cross-decoder layers, allowing for token-level top-k selection to be computed once and reused across layers

**Why It Matters:** This innovation enables significant decoding speedup and overall throughput improvement, making it a more complete architectural solution for long-context language models that advances both model quality and inference efficiency

**Tags:** sparse attention, large language models, long-context inference, efficiency optimization, cross-layer sparse attention

**Link:** [http://arxiv.org/abs/2606.06467v1](http://arxiv.org/abs/2606.06467v1)

## 3. Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads

**Authors:** Yasmine Omri, Ziyu Gan, Zachary Broveak, Robin Geens, Zexue He, Alex Pentland, Marian Verhelst, Tsachy Weissman, Thierry Tambe

**TL;DR:** This paper characterizes and analyzes the system-level behavior of agent memory systems used in long-horizon tasks, providing insights and recommendations for improving their performance and efficiency

**Key Innovation:** A system-oriented taxonomy and phase-aware profiling harness for agent memory systems, enabling the characterization of their cost and performance across construction, retrieval, and generation phases

**Why It Matters:** The findings and recommendations of this paper can help improve the design and deployment of agent memory systems, enabling more efficient and effective long-horizon reasoning and interaction in applications such as conversational AI and decision support systems

**Tags:** Agent Memory, Long-Horizon Workloads, LLM Agents, System Characterization, Artificial Intelligence

**Link:** [http://arxiv.org/abs/2606.06448v1](http://arxiv.org/abs/2606.06448v1)
